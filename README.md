# ATech // Signal Field

A redesign concept for [atech.si](https://www.atech.si/): one live GPU filament field that morphs as you scroll, Space Mono typography, glass dashboard cards and synthesized UI sounds.

Built with Three.js, GSAP + ScrollTrigger and Lenis, all loaded from CDNs. There is no build step.

## Run locally

Serve the folder with any static server, e.g.

```bash
npx http-server -p 5173 -c-1
```

then open http://localhost:5173.
